# Sourced figures

Check the actual figure's reuse terms before incorporating it. Prefer official
project pages, author pages, Wikimedia file pages, and articles with explicit
compatible licenses. An open-access location alone does not establish permission
for third-party images embedded in an article.

1. Match the visual itself, using distinctive labels, panels, or plotted values.
   A method citation is not necessarily the visual's source.
2. Record the source URL, license or confirmed reuse authority, asset path, and
   modifications in the figure script, manifest, or task notes.
3. Download the original vector or highest useful raster resolution.
4. Explain the scientific point in the caption and add concise verified credit.
   Use “Adapted from” or “Redrawn from” when appropriate.

When permission for a particular image is unclear, continue with independent
work. Use a compatible source or an original explanation of the underlying idea
when that fits the user's request; redrawing does not itself grant permission
to copy a protected composition.

For confirmed lecture-deck reuse, use
[lecture extraction](../../lecture-adaptation/references/extraction.md).
Preserve the authorization already given for that deck and its embedded figures.

Keep detailed provenance in agent-facing records. The caption should identify
what the reader sees, not describe extraction tools or migration procedures.
An uncertain visual origin must not be upgraded into a verified paper attribution.
