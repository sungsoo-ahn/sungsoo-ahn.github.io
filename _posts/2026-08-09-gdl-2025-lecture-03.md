## Graph representation learning and message passing

Graphs are a general language for entities connected by relations or interactions. The entities become vertices, while chemical bonds, social ties, physical contacts, transactions, and communication links become edges.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-5.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Examples of graphs across scientific and social domains." caption="Graphs place many kinds of relational data inside one representation. Cropped from the 2025 GDL graph-neural-network lecture, slide 5." %}

For an undirected graph $$G=(V,E)$$, the vertex set contains nodes $$u\in V$$ and the edge set contains unordered pairs $${u,v}\in E$$. An equivalent storage form is the adjacency matrix $$A\in\{0,1\}^{n\times n}$$. Each node can carry a feature $$x_u\in\mathbb R^d$$, collected into $$X\in\mathbb R^{n\times d}$$, and each edge can carry an attribute $$e_{uv}$$.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-6.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Definition of graph representation learning with node features and edge attributes." caption="Graph representation learning starts from an explicit contract for vertices, edges, node features, and edge attributes. Cropped from the 2025 GDL graph-neural-network lecture, slide 6." %}

The output contract varies with the problem. Node-level prediction assigns a target $$y_u$$ to each vertex, edge-level prediction assigns $$y_{uv}$$ to an edge, and graph-level prediction returns one target $$y$$ for the entire graph.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-7.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Node, edge, and graph prediction targets." caption="Node-, edge-, and graph-level tasks differ in the index structure of the output. Cropped from the 2025 GDL graph-neural-network lecture, slide 7." %}

The lecture separates graph neural networks into two broad computational patterns. Message-passing networks communicate along stored edges and are therefore sparsely connected. Graph Transformers can connect every pair of nodes, but then require an explicit way to recover graph structure.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-8.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Sparse message passing and fully connected Transformer graph networks." caption="Sparse message passing and fully connected attention are the two main graph-network patterns developed in the lecture. Cropped from the 2025 GDL graph-neural-network lecture, slide 8." %}

### The message-passing layer

At layer $$\ell$$, a message-passing neural network first computes a message from neighbor $$u$$ to node $$v$$,

$$
m_{uv}^{(\ell)}=operatorname{MESSAGE}^{(\ell)}
\left(h_u^{(\ell-1)},e_{uv}\right),
$$

and then aggregates the multiset of incoming messages,

$$
h_v^{(\ell)}=operatorname{AGGREGATE}^{(\ell)}
\left(\{m_{uv}^{(\ell)}:u\in N(v)\},h_v^{(\ell-1)}\right).
$$

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-9.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Message computation and aggregation in an MPNN layer." caption="An MPNN alternates edge-wise message computation with permutation-invariant neighborhood aggregation. Cropped from the 2025 GDL graph-neural-network lecture, slide 9." %}

A typical message function applies an MLP to a concatenation of the sender state and edge feature. The aggregation must accept a variable-size neighborhood without depending on its order, so sum, mean, and max pooling are standard choices.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-10.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Typical MPNN message function with sum and mean aggregation." caption="Node-wise learned messages and symmetric pooling turn a variable-size neighborhood into a fixed-width node state. Cropped from the 2025 GDL graph-neural-network lecture, slide 10." %}

The graph convolutional network is a basic instance. Starting from $$h_v^{(0)}=x_v$$, it averages neighboring states, applies a trainable transformation, includes a self transformation, and passes the result through a nonlinearity:

$$
h_v^{(\ell+1)}=sigma\left(
W_\ell\frac{1}{|N(v)|}\sum_{u\in N(v)}h_u^{(\ell)}
+B_\ell h_v^{(\ell)}
\right).
$$

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-11.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph convolutional network neighborhood update." caption="GCN combines normalized neighborhood averaging, a self term, trainable weights, and a nonlinearity. Cropped from the 2025 GDL graph-neural-network lecture, slide 11." %}

Writing all node states as rows of $$H^{(\ell)}$$ exposes the sparse linear algebra:

$$
H^{(\ell+1)}=sigma\left(\widetilde A H^{(\ell)}W_\ell+H^{(\ell)}B_\ell\right),
\qquad \widetilde A=D^{-1}A.
$$

The normalized adjacency performs neighborhood aggregation; the second term transforms each node independently. Efficient sparse matrix multiplication is therefore central to scaling GCN-like models, and GPU support for sparse operations remains an active systems problem.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-12.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Matrix formulation of a graph convolutional network." caption="The matrix form separates sparse adjacency aggregation from the node-wise self transformation. Cropped from the 2025 GDL graph-neural-network lecture, slide 12." %}

GraphSAGE, GIN, and GatedGCN fit the same message-and-aggregate template. They vary the node transformation, pooling rule, or recurrent update: GraphSAGE uses learned node transformations with mean pooling, GIN emphasizes an MLP with sum pooling, and GatedGCN uses gates and recurrent-style state updates. Architecture names obscure how much of the design space is a choice of these components.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-13.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GraphSAGE, GIN, and GatedGCN as variations of message passing." caption="Several named GNNs are variations of the same message, aggregation, and update interface. Cropped from the 2025 GDL graph-neural-network lecture, slide 13." %}

## Attention on graph neighborhoods

Graph attention replaces fixed pooling with learned, neighbor-dependent weights. The message stage is unchanged in form; the aggregation becomes

$$
h_v^{(\ell)}=sum_{u\in N(v)}\alpha_{uv}W_Vh_u^{(\ell-1)}.
$$

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-15.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Attention pooling replacing ordinary neighborhood aggregation in a GNN." caption="Graph attention keeps edge-local communication but learns how strongly each neighbor contributes. Cropped from the 2025 GDL graph-neural-network lecture, slide 15." %}

In dot-product form, the score and normalized weight are

$$
s_{uv}=(W_Qh_v)^\top(W_Kh_u),
\qquad
\alpha_{uv}=\frac{\exp s_{uv}}
{\sum_{u'\in N(v)}\exp s_{u'v}}.
$$

If the neighborhood is expanded from $$N(v)$$ to the full vertex set $$V$$, this update becomes a Transformer layer.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-16.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph attention coefficients defined by normalized query-key scores." caption="Restricting attention to graph neighborhoods gives GAT; attending over all vertices gives the Transformer pattern. Cropped from the 2025 GDL graph-neural-network lecture, slide 16." %}

The original GAT implementation does not use the Transformer inner product exactly. It concatenates transformed endpoint features and applies a learned linear scoring function before normalization. The lecture emphasizes this practical distinction: the family resemblance lies in adaptive weighted aggregation, not in identical score parameterization.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-17.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Original GAT concatenation score compared with Transformer dot-product attention." caption="GAT uses concatenation and a learned linear score rather than the standard Transformer inner product. Cropped from the 2025 GDL graph-neural-network lecture, slide 17." %}

## Graph Transformers need graph structure

A Transformer receives a sequence of feature vectors, not a graph by default. The first question is therefore how to present graph structure to an architecture whose attention can connect every node pair.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-19.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="A graph being converted into a sequence for a Transformer." caption="A graph Transformer must decide how vertices and graph structure enter a sequence-style architecture. Cropped from the 2025 GDL graph-neural-network lecture, slide 19." %}

Vanilla self-attention updates

$$
h_v^{(\ell)}=sum_{u\in V}\alpha_{uv}W_Vh_u^{(\ell-1)},
\qquad
\alpha_{uv}=\operatorname{softmax}_{u\in V}
\left((W_Qh_v)^\top(W_Kh_u)\right).
$$

This expression contains no adjacency matrix. Without extra inputs, it knows the multiset of node features but not which vertices are connected.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-20.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Transformer attention over graph nodes with missing adjacency information." caption="Fully connected attention discards stored adjacency unless graph structure is supplied separately. Cropped from the 2025 GDL graph-neural-network lecture, slide 20." %}

Natural-language Transformers solve an analogous order problem with positional encodings: the word embedding alone does not say whether a token appeared first or fifth. Graphs require positional or structural encodings that respect their non-sequential geometry.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-21.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Sequence positional encoding motivating graph positional features." caption="Attention is order-blind without positional information; graph Transformers face the corresponding structure-blindness problem. Cropped from the 2025 GDL graph-neural-network lecture, slide 21." %}

### Laplacian eigenvectors

For the combinatorial Laplacian $$L=D-A$$, an eigenvector satisfies

$$
Lv_k=\lambda_kv_k.
$$

Stacking several eigenvectors gives a matrix whose $$i$$th row can be attached to node $$i$$ as a positional feature.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-22.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Laplacian eigenvectors used as node positional encodings." caption="Rows of a truncated Laplacian eigenbasis provide graph-dependent node positions. Cropped from the 2025 GDL graph-neural-network lecture, slide 22." %}

Each graph has its own Laplacian, so the encoding is derived from its connectivity. The lecture presents these eigenvectors as a graph analogue of sinusoidal positional embeddings; the spectral interpretation is developed in the following lecture.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-23.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph Laplacian matrix and eigenvectors as sinusoidal analogues." caption="The graph Laplacian carries structure, and its eigenvectors generalize frequency-like coordinates to graphs. Cropped from the 2025 GDL graph-neural-network lecture, slide 23." %}

### Pairwise structural bias

Structure can also enter the attention matrix directly. A learned bias $$b_{uv}$$ based on shortest-path distance or edge types modifies the score:

$$
\alpha_{uv}=\operatorname{softmax}_{u\in V}
\left(b_{uv}+\frac{(W_Qh_v)^\top(W_Kh_u)}{\sqrt d}\right).
$$

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-24.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Shortest-path bias added to graph Transformer attention." caption="Pairwise shortest-path or edge-type biases inject graph structure directly into attention scores. Cropped from the 2025 GDL graph-neural-network lecture, slide 24." %}

GraphGPS++ combines local message passing with global Transformer blocks and substantial feature engineering. The lecture uses its molecular results to make two practical points: hybrid designs work well, and graph architectures can exhibit scaling behavior when both model and data are enlarged.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-25.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GraphGPS++ hybrid message passing and Transformer architecture with scaling curve." caption="GraphGPS++ is an optimized hybrid of message passing, attention, and molecular features. Cropped from the 2025 GDL graph-neural-network lecture, slide 25." %}

## A chronological map of graph architectures

The lecture next changes register. Rather than derive one more layer, it follows how graph-network ideas accumulated from convolution, random walks, and message passing to expressivity, long-range propagation, and scaling. The sequence is useful because later architectures often repair a limitation exposed by earlier ones.

### From graph convolution to a shared message-passing language

An early 2013 attempt to generalize convolution clustered graph vertices and pooled each cluster into a coarser vertex; it also proposed a spectral version. This already exposed two enduring questions: what replaces translation on a graph, and what should graph pooling preserve?

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-27.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Early convolutional network on graph-structured data." caption="Early graph convolution combined graph clustering, pooling, and spectral filtering. Cropped from the 2025 GDL graph-neural-network lecture, slide 27." %}

ChebNet localized spectral filtering with Chebyshev polynomials of the graph Laplacian. Its layer applies a polynomial filter,

$$
H^{(\ell+1)}=\sum_k\theta_k L^kH^{(\ell)},
$$

connecting spectral convolution to finite-hop message propagation.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-28.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="ChebNet spectral graph convolution and localized filtering." caption="ChebNet approximates spectral filters with Laplacian polynomials that remain localized on the graph. Cropped from the 2025 GDL graph-neural-network lecture, slide 28." %}

Node2Vec approached representation learning from random walks. It samples sequences beginning at a node, then applies sequence-learning machinery; its biased walk interpolates between breadth-first and depth-first exploration.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-29.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Node2Vec random walks balancing breadth-first and depth-first exploration." caption="Node2Vec learns node embeddings from biased random-walk contexts. Cropped from the 2025 GDL graph-neural-network lecture, slide 29." %}

GCN simplified the spectral route to a first-order approximation that can be implemented as normalized message passing. Its influence came partly from making graph convolution easy to express and train.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-30.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GCN paper and first-order spectral approximation." caption="GCN turned a spectral approximation into a simple neighborhood propagation rule. Cropped from the 2025 GDL graph-neural-network lecture, slide 30." %}

The neural message-passing framework then provided a general vocabulary for learned edge messages and node updates, demonstrated on quantum-chemistry tasks such as QM9.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-31.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Neural Message Passing for Quantum Chemistry framework." caption="MPNN supplied a common message-and-update abstraction and connected it to molecular prediction. Cropped from the 2025 GDL graph-neural-network lecture, slide 31." %}

GraphSAGE targeted inductive learning on large graphs. Neighbor sampling improves scalability, while its analysis connects aggregation to the Weisfeiler--Lehman graph-isomorphism procedure.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-32.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GraphSAGE sampling and inductive representation learning." caption="GraphSAGE samples neighborhoods to learn inductive node representations at scale. Cropped from the 2025 GDL graph-neural-network lecture, slide 32." %}

Relational GCN assigns transformations according to edge relation type. This makes the message function depend explicitly on $$r(u,v)$$ and supports multi-relational graphs such as knowledge graphs.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-33.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Relational GCN with relation-specific transformations." caption="R-GCN conditions messages on typed relations rather than treating every edge identically. Cropped from the 2025 GDL graph-neural-network lecture, slide 33." %}

GatedGCN weights messages with pair-dependent gates. The gate resembles attention, except it is not normalized across the neighborhood.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-34.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Residual GatedGCN architecture and gated message update." caption="GatedGCN learns unnormalized edge gates for residual message propagation. Cropped from the 2025 GDL graph-neural-network lecture, slide 34." %}

GAT normalized such pair-dependent weights and proposed its concatenation-based score. It made learned neighborhood selection a standard GNN primitive.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-35.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph Attention Network message-passing formula and attention neighborhood." caption="GAT introduced normalized learned weights over graph neighborhoods. Cropped from the 2025 GDL graph-neural-network lecture, slide 35." %}

### Depth, pooling, expressivity, and fair comparison

Jumping Knowledge Networks analyzed how repeated propagation can lose local information and combined representations from several depths. The lecture highlights the importance of residual or skip pathways rather than assuming that the deepest state is always best.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-36.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Jumping Knowledge Network combining representations from multiple depths." caption="JK-Net preserves information from different receptive-field depths instead of using only the final layer. Cropped from the 2025 GDL graph-neural-network lecture, slide 36." %}

DiffPool learned a soft assignment of vertices to clusters, producing hierarchical graph representations. The slide also records the lecturer's judgment that pooling has often been less reliable for graphs than its central role in image CNNs might suggest.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-37.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Differentiable graph pooling through a learned assignment matrix." caption="DiffPool learns a soft node-to-cluster assignment for hierarchical graph coarsening. Cropped from the 2025 GDL graph-neural-network lecture, slide 37." %}

GIN formally connected message-passing expressivity to the Weisfeiler--Lehman test. Its use of sum aggregation and an MLP was designed to preserve multiset distinctions that weaker aggregation can lose; the work triggered a large literature on what GNNs can distinguish.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-38.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph Isomorphism Network and WL expressivity examples." caption="GIN tied injective multiset aggregation to the distinguishing power of the WL test. Cropped from the 2025 GDL graph-neural-network lecture, slide 38." %}

Simplifying Graph Convolution removed many intermediate nonlinearities and collapsed propagation into repeated linear diffusion followed by one learned transformation. Its empirical message was that some graph benchmarks do not require a deep stack of nonlinear processing.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-39.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Simplified Graph Convolution architecture and propagation rule." caption="SGC asks how much of GCN performance comes from linear graph propagation alone. Cropped from the 2025 GDL graph-neural-network lecture, slide 39." %}

A fair-comparison study then showed that small TU graph-classification datasets can yield high variance and statistically unstable rankings. This changes the interpretation of architecture improvements: a table winner is not automatically a reliable method advance.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-40.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Fair comparison of GNNs on small graph-classification datasets." caption="Controlled evaluation exposed the statistical fragility of rankings on small graph benchmarks. Cropped from the 2025 GDL graph-neural-network lecture, slide 40." %}

PNA emphasized aggregation itself. It combines multiple statistics and degree-scalers instead of choosing only sum, mean, or max, improving the information retained from heterogeneous neighborhoods.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-41.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Principal Neighbourhood Aggregation with multiple aggregators and scalers." caption="PNA combines neighborhood statistics because no single pooling rule captures every distribution. Cropped from the 2025 GDL graph-neural-network lecture, slide 41." %}

GCNII addressed the observation that adding GNN layers often fails to improve performance. Initial residual connections and identity mapping make much deeper propagation trainable without immediately erasing the original node signal.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-42.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GCNII deep graph convolutional network results and design." caption="GCNII uses initial residual and identity-mapping mechanisms to stabilize deep graph propagation. Cropped from the 2025 GDL graph-neural-network lecture, slide 42." %}

### Transformers, richer structures, and long-range propagation

An early Graph Transformer attached Laplacian eigenvectors as positional information, making the spectral coordinates from the first part of the lecture part of a Transformer architecture.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-43.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph Transformer using Laplacian eigenvector positions." caption="The early Graph Transformer supplied spectral positional information to attention layers. Cropped from the 2025 GDL graph-neural-network lecture, slide 43." %}

A systematic search over the GNN design space found that the best architecture differs across tasks. The lecture draws a deliberately skeptical conclusion: claims that one new layer is universally best deserve scrutiny, and architecture papers are hard to interpret without controlled design-space searches.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-44.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Design-space search for graph neural networks across datasets." caption="Design-space experiments show that strong graph architectures depend on the task and evaluation regime. Cropped from the 2025 GDL graph-neural-network lecture, slide 44." %}

Graph Substructure Networks augment node representations with counts of selected subgraphs. These features distinguish examples that ordinary message-passing networks cannot separate.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-45.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph Substructure Networks with subgraph isomorphism counts." caption="Substructure counts add graph information beyond ordinary local message passing. Cropped from the 2025 GDL graph-neural-network lecture, slide 45." %}

Higher-order approaches lift a graph into simplicial or cellular structures and pass messages between edges, faces, cells, or hyperedges. The representation changes before the neural network begins: higher-order relations become explicit computational objects.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-46.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Message passing on simplicial complexes and cellular networks." caption="Higher-order GNNs lift graphs into richer combinatorial complexes and communicate among their cells. Cropped from the 2025 GDL graph-neural-network lecture, slide 46." %}

Graphormer combined shortest-path distance, edge types, and node degree as spatial, edge, and centrality encodings. Its results showed that Transformers need not perform poorly on graphs when their structural inputs are designed carefully.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-47.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graphormer structural encodings and architecture." caption="Graphormer injects shortest paths, edge types, and centrality into global attention. Cropped from the 2025 GDL graph-neural-network lecture, slide 47." %}

GRAND interpreted graph propagation as a continuous-time diffusion process. This neural-ODE view makes over-smoothing analyzable as heat diffusion and offers ways to modify or control it.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-48.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph neural diffusion as a continuous-time process." caption="GRAND models graph representation flow as a differential equation related to heat diffusion. Cropped from the 2025 GDL graph-neural-network lecture, slide 48." %}

Over-squashing is a different long-range failure: information from an exponentially growing receptive field must pass through fixed-width bottlenecks. The curvature analysis in the lecture motivates graph rewiring as a way to shorten or widen those routes.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-49.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Oversquashing bottleneck and graph curvature illustration." caption="Over-squashing compresses distant information through narrow graph bottlenecks; rewiring changes the communication geometry. Cropped from the 2025 GDL graph-neural-network lecture, slide 49." %}

GNN-AK runs a base GNN on local subgraphs rather than representing every neighborhood as a star. This local-kernel perspective improves structural awareness beyond ordinary MPNNs and beyond using counts alone.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-50.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GNN As Kernel using local subgraphs around vertices." caption="GNN-AK processes induced local subgraphs instead of reducing each neighborhood to a star. Cropped from the 2025 GDL graph-neural-network lecture, slide 50." %}

Equivariant Subgraph Aggregation Networks generate subgraphs by dropping vertices and aggregate predictions across them. Graphs that a standard MPNN treats identically can become distinguishable after this symmetry-aware subgraph decomposition.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-51.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Equivariant Subgraph Aggregation Networks and node-drop subgraphs." caption="ESAN increases expressive power by applying a shared GNN to a permutation-consistent collection of subgraphs. Cropped from the 2025 GDL graph-neural-network lecture, slide 51." %}

GPS synthesized the emerging recipe: combine local message passing with global attention, and treat positional and structural encodings as first-class design choices. Its claim is architectural and empirical rather than a single new layer formula.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-52.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GPS graph Transformer combining message passing and global attention." caption="GPS combines a local MPNN, a global Transformer, and structural encodings in each layer. Cropped from the 2025 GDL graph-neural-network lecture, slide 52." %}

GPS++ returned the focus to molecular property prediction and extensive message-passing engineering. Its title—“reviving the art of message passing”—captures the lecture's broader lesson that careful local architectures remain competitive beside Transformers.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-53.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GPS++ molecular message-passing architecture and paper results." caption="GPS++ shows how a carefully optimized message-passing system can remain state of the art for molecular graphs. The final architecture slide asks about scaling. On sufficiently large molecular datasets and with larger parameter counts, established GNN designs can continue improving; this shifts attention from inventing another layer toward obtaining suitable data and training systems.

## Datasets define the graph-learning problem

The lecture ends by organizing datasets according to what they demand from a graph model. This is not an appendix: the architecture claims in the preceding timeline depend on the scale, target, structure, and generalization regime of the benchmark.

TU datasets collect small chemical, biological, and social graph-classification problems. Their small sample sizes can produce high variance and misleading architecture rankings unless experimental design is unusually careful.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-56.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="TU graph dataset collection and benchmark table." caption="TU datasets are convenient small-scale benchmarks, but their variance limits strong architecture conclusions. Cropped from the 2025 GDL graph-neural-network lecture, slide 56." %}

CiteSeer, Cora, and PubMed are canonical node-classification datasets. They are closely associated with homophily: nearby vertices often share labels, making neighborhood smoothing especially effective and also narrowing what a benchmark tests.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-57.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="CiteSeer, Cora, and PubMed citation-network datasets." caption="Citation-network benchmarks emphasize node prediction under graph homophily. Cropped from the 2025 GDL graph-neural-network lecture, slide 57." %}

MoleculeNet, ZINC250k, and PCQMv2 contain molecular graphs without explicit three-dimensional coordinates. They provide immediate property-prediction applications, but strong performance often depends on chemical featurization as well as the neural architecture.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-58.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="MoleculeNet, ZINC, and PCQM molecular graph datasets." caption="Two-dimensional molecular benchmarks test property prediction and the value of chemistry-aware features. Cropped from the 2025 GDL graph-neural-network lecture, slide 58." %}

Large real graphs create a systems problem. Architectures and training algorithms must handle graphs that do not fit into ordinary dense computation, often using sampling, partitioning, or distributed execution.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-59.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Large-scale node, link, and graph benchmarks." caption="Large graph benchmarks evaluate scalability as well as predictive performance. Cropped from the 2025 GDL graph-neural-network lecture, slide 59." %}

The Long Range Graph Benchmark was designed because local GNNs are not automatically good at long-range interaction. Its tasks stress communication beyond a few graph hops rather than rewarding only local smoothing.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-60.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Long Range Graph Benchmark tasks and results." caption="LRGB isolates long-range dependencies that short-range message passing can miss. Cropped from the 2025 GDL graph-neural-network lecture, slide 60." %}

Temporal graph benchmarks attach timestamps to events or edges. Static message-passing assumptions are insufficient when order and time gaps carry information, so temporal models need their own architectures and evaluation protocols.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-61.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Temporal Graph Benchmark tasks and dataset table." caption="Temporal graph benchmarks add event time and require time-aware representation and evaluation. Cropped from the 2025 GDL graph-neural-network lecture, slide 61." %}

Algorithmic reasoning asks whether a GNN can represent the execution of algorithms on graphs. The target is not only a label but a structured sequence of intermediate computational states, and one aspiration is an architecture expressive enough to model broad families of algorithms.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-62.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Algorithmic reasoning benchmark for graph neural networks." caption="Algorithmic-reasoning datasets test whether graph networks can emulate structured computation. Cropped from the 2025 GDL graph-neural-network lecture, slide 62." %}

Knowledge-graph reasoning answers structured queries by traversing typed relations and composing evidence. The lecture closes with the contemporary combination of language models and GNNs for these tasks, while noting the field's strong claims that some benchmarks are nearing saturation.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-03/slide-63.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Knowledge graph query reasoning with language models and GNNs." caption="Knowledge-graph reasoning combines relational structure with increasingly language-based representations. Cropped from the 2025 GDL graph-neural-network lecture, slide 63." %}

The sequence from MPNNs to graph Transformers can be summarized as a repeated negotiation among locality, structure, expressive power, long-range communication, and computational scale. The benchmark sequence adds the missing condition: each tradeoff matters only relative to the graphs, targets, and deployment regime on which it is measured.
