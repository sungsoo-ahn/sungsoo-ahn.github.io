## From TFN convolution to steerable attention

The lecture compares SE(3)-Transformer, Equiformer, MACE, eSCN, and EquiformerV2. Each retains typed equivariant features, but changes a different part of the computation.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-3.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Overview of recent steerable geometric GNN architectures." caption="The source organizes recent advances around attention, higher body order, efficient tensor products, and higher-degree scaling. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 3." %}

Tensor Field Networks provide the baseline. Each point carries typed features, and each edge couples a spherical-harmonic filter to the source feature through a Clebsch--Gordan product.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-4.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="TFN typed convolution and spherical harmonic filtering." caption="TFN supplies the typed convolution modified by every architecture in this lecture. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 4." %}

The hidden tensor has point, channel, degree, and representation indices. Learned channel mixing must not arbitrarily mix the representation coordinates within a degree.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-5.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="TFN point channel degree and representation indices." caption="Channel multiplicity and irrep coordinates play different roles in a steerable hidden state. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 5." %}

The filter separates distance and direction,

$$
F^{(l_f)}(r)=R^{(l_f)}(\lVert r\rVert)Y^{(l_f)}(\hat r),
$$

then couples it to an input type through fixed Clebsch--Gordan coefficients.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-6.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="TFN radial times spherical harmonic filter." caption="A learned invariant radial factor multiplies a fixed typed angular basis. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 6." %}

Summing these typed filter--feature products over neighbors yields the TFN message. Only output degrees satisfying the triangle rule appear.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-7.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="TFN Clebsch Gordan neighbor aggregation." caption="TFN aggregates legal filter--input couplings into each output type. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 7." %}

The same layer can be read in three stages: couple two typed vectors, condition the coupling on an edge direction and distance, then sum the resulting message over neighbors.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-8.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="TFN product edge conditioning and message aggregation stages." caption="The simplified equations isolate tensor coupling, geometric conditioning, and graph aggregation. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 8." %}

SE(3)-Transformer adds nonlinear pairwise attention. The attention coefficient must be invariant, so it is generated from inner products between like-typed query and key features.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-9.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="SE3 Transformer invariant attention motivation." caption="Attention changes neighbor importance while keeping the selection scalar invariant. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 9." %}

Writing the TFN convolution as a typed kernel $$W^{lk}(x_j-x_i)$$ makes the modification explicit: the kernel maps input type $$k$$ to output type $$l$$.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-10.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="TFN layer rewritten as typed kernels for SE3 Transformer." caption="The radial, harmonic, and Clebsch--Gordan pieces are packaged into a typed value kernel. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 10." %}

SE(3)-Transformer keeps the self-interaction and multiplies each neighbor value by a type-$$0$$ coefficient:

$$
f_{i,\mathrm{out}}^{(l)}
=W_V^{ll}f_{i,\mathrm{in}}^{(l)}
+\sum_{j\in\mathcal N(i)}\alpha_{ij}
\sum_kW_V^{lk}(x_j-x_i)f_{j,\mathrm{in}}^{(k)}.
$$

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-11.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="SE3 Transformer attention weighted typed value update." caption="The invariant coefficient changes message strength without changing its output type. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 11." %}

The softmax uses an invariant query--key inner product. The values remain steerable TFN-like transformations.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-12.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Invariant queries keys and softmax in SE3 Transformer." caption="Like-type inner products produce valid scalar attention logits. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 12." %}

Nonlinear self-interaction mixes channels using scalar functions of invariant feature statistics, while excluding self-edges from the pairwise attention sum.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-13.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="SE3 Transformer nonlinear self interaction." caption="Pointwise channel mixing complements neighbor attention inside the steerable block. ## Equiformer: a practical equivariant Transformer

Equiformer turns steerable attention into a practical deep Transformer block. It combines multilayer-perceptron attention with nonlinear message passing and adds normalization and gated SiLU/sigmoid operations.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-15.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Equiformer block and practical implementation details." caption="Equiformer packages equivariant attention, nonlinear messages, gates, and normalization into a repeatable architecture. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 15." %}

Linear layers mix multiplicity channels within the same type. Layer normalization likewise respects type, rather than normalizing representation entries as unrelated scalars.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-16.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Equiformer typed linear layer and layer normalization." caption="Equiformer's pointwise operations preserve the grouping of components belonging to one irrep. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 16." %}

Its depth-wise tensor product is analogous to depth-wise convolution: one output irrep depends on one corresponding input irrep rather than every channel pair. The restriction reduces the cost of Clebsch--Gordan mixing.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-17.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Equiformer depth wise tensor product." caption="Depth-wise tensor products trade dense channel coupling for a cheaper structured interaction. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 17." %}

Equiformer reports competitive QM9 performance and state-of-the-art results on MD17 and OC20.

## MACE: explicit higher body order

Atomic cluster expansion organizes an atom's environment by body order. MACE imports this idea into equivariant message passing: instead of relying on many graph layers to build multi-neighbor correlations, it forms higher-order Clebsch--Gordan products within a layer.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-20.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Atomic cluster expansion and MACE body order message hierarchy." caption="MACE expands a local environment into one-neighbor, two-neighbor, through higher-correlation contributions. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 20." %}

In the lecture's decomposition, one layer first aggregates ordinary TFN-like neighbor features. A second node-wise layer takes higher-order Clebsch--Gordan products of the aggregated features, like a high-order geometric $$1\times1$$ convolution.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-21.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="MACE neighbor aggregation and node wise high order tensor products." caption="MACE separates gathering geometric neighbor information from forming higher body-order correlations at the center. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 21." %}

The node update combines a residual feature with a higher-order message, with element-dependent linear weights for the receiver atom.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-22.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="MACE node update and channel weights." caption="Element-conditioned linear mixing combines node state and body-ordered message. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 22." %}

The message sums over correlation orders $$\nu$$ and over compatible sequences of intermediate angular momenta.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-23.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="MACE sum over correlation orders and paths." caption="Each correlation order contributes a generalized tensor product to the typed message. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 23." %}

The generalized product $$B_{i,\eta_\nu kLM}$$ couples $$\nu$$ copies of the aggregated feature through chained Clebsch--Gordan coefficients. This is the explicit high-order part of MACE.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-24.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="MACE generalized high order Clebsch Gordan tensor product." caption="A chain of Clebsch--Gordan couplings maps several neighbor-aggregated features into one output type. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 24." %}

Those node-wise products act on features that already contain a sum over the receiver's neighborhood, so multiplying them generates multi-neighbor correlations without enumerating neighbor tuples directly.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-25.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="MACE neighbor aggregated feature inside higher order product." caption="Aggregation followed by products produces many-body terms from compact neighborhood summaries. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 25." %}

A correlation order $$\nu$$ is implemented as a sequence of $$\nu$$ tensor products along allowed intermediate types; the practical model commonly uses $$\nu=3$$.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-26.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Sequence of generalized Clebsch Gordan products in MACE." caption="Higher correlation order corresponds to a longer coupling path through intermediate angular momenta. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 26." %}

MACE reports state-of-the-art revised-MD17 errors and reaches strong performance with only a few message-passing layers. The source interprets the shallow depth as evidence that explicit body order replaces interactions that earlier models had to accumulate across depth.

## eSCN: reducing SO(3) products to SO(2)

High-degree Clebsch--Gordan products are expensive. eSCN reduces their cost without approximating the equivariant operation by rotating each edge direction onto a fixed axis, where the spherical-harmonic vector becomes sparse.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-29.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="eSCN tensor product complexity and sparse reformulation." caption="eSCN targets the angular tensor product rather than reducing the number of geometric feature types. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 29." %}

Choose a rotation $$R_{st}$$ that aligns $$\hat r_{st}$$ with the reference axis. In that frame,

$$
Y_m^{(l)}(R_{st}\hat r_{st})=0
\quad\text{for}\quad m\ne0.
$$

The Wigner matrix rotates input features into this aligned frame and rotates outputs back.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-30.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="eSCN rotation aligning an edge with the reference axis." caption="Axis alignment makes all nonzero magnetic-index components of the edge harmonic vanish. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 30." %}

The resulting tensor product no longer sums over the filter index $$m_f$$; only $$m_f=0$$ survives.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-31.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="eSCN tensor product after eliminating zero harmonic terms." caption="Rotating to the edge frame removes a full angular summation exactly. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 31." %}

Additional sparsity in the Clebsch--Gordan coefficients reduces the operation further.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-32.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Further eSCN reduction using sparse Clebsch Gordan coefficients." caption="The remaining aligned-axis product decomposes into smaller structured contractions. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 32." %}

Equivalently, alignment reduces the three-dimensional spherical interaction to circular harmonics around the edge axis: the residual symmetry is $$SO(2)$$.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-33.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="eSCN explanation as circular harmonics around an aligned edge." caption="After fixing the edge direction, only rotations about that axis remain, reducing the coupling from SO(3) to SO(2). Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 33." %}

Experiments report state-of-the-art accuracy with faster runtime.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-34.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="eSCN benchmark accuracy and runtime." caption="The evaluation tests whether the exact sparse reformulation improves the accuracy--cost frontier. ## EquiformerV2: high-degree attention at scale

EquiformerV2 combines eSCN convolution with separable spherical activation, attention renormalization, and separable layer normalization.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-35.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="EquiformerV2 architecture and key ingredients." caption="EquiformerV2 integrates efficient tensor products with revised activation and normalization. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 35." %}

Equiformer's original gate lets scalar channels modulate higher-degree features. The separable spherical activation instead converts all degrees to samples on the sphere, applies an unconstrained pointwise activation, and transforms the samples back through an inverse spherical Fourier transform.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-36.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="EquiformerV2 separable spherical activation." caption="Spherical sampling lets nonlinear interactions involve all degrees rather than only scalar gates. Cropped from the 2025 GDL advanced-steerable-GNN lecture, slide 36." %}

Separate normalization of each degree can destabilize scalar features formed from several types. Attention renormalization and separable layer normalization address this cross-type scale problem.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-37.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="EquiformerV2 attention and layer normalization changes." caption="The normalization changes target unstable mixing across different representation degrees. ## The surrounding design space

LieConv generalizes convolution to Lie groups on continuous data; e3nn provides a general library for Euclidean-equivariant functions; Allegro learns local equivariant representations for large-scale dynamics; and BOTNet connects atom-centered potentials to body-ordered tensor networks.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-40.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Related equivariant models LieConv e3nn Allegro and BOTNet." caption="The first related-work map separates general equivariant frameworks from local atomistic and body-ordered models. SCN precedes eSCN with spherical channels, EQGAT brings equivariant attention to molecular properties, and the Equivariant Transformer targets neural molecular potentials.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-11/slide-41.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Related models SCN EQGAT and Equivariant Transformer." caption="The second map locates efficient spherical channels and alternative equivariant attention models. The architectures improve different axes. Attention makes neighbor weighting adaptive. Equiformer turns that idea into a stable deep block. MACE exposes higher body order inside a shallow model. eSCN reduces the angular product exactly by aligning each edge. EquiformerV2 combines the efficient product with higher-degree activations and cross-type normalization. Their benchmark gains are therefore attached to different computational and representational changes, not to one generic notion of “more equivariance.”
