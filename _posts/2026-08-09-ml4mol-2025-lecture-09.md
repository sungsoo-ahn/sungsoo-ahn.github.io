## Generating molecular graphs

The motivating question is direct: how can we generate molecules with desired properties? In practice, an interactive design system may combine a structural model, a property prompt, and a generative backend that proposes candidates rather than selecting only from an existing library.

At the distributional level, suppose observed graphs follow an unknown data distribution $$p_{\mathrm{data}}(G)$$. A generative model learns $$p_{\mathrm{model}}(G;\theta)$$ and then samples new graphs from it.

This definition leaves open the central implementation choice: what sequence of valid decisions constructs a graph?

### Autoregressive generation

An autoregressive model uses the chain rule. For a sequence of construction actions $$x=(x_1,\ldots,x_T)$$,

$$
p_{\mathrm{model}}(x;\theta)
=\prod_{t=1}^{T}
p_{\mathrm{model}}(x_t\mid x_1,\ldots,x_{t-1};\theta).
$$

The same conditional model supports density estimation under teacher forcing and sampling by repeatedly drawing the next action. For a graph, an action may add a node, add an edge, or stop.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s04-image5.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Autoregressive graph-generation equation expressing a joint action probability as conditional factors." caption="Autoregressive graph generation factorizes the construction probability into node and edge actions. Reused from the 2025 ML4Mol molecular generation lecture, slide 4." %}

The factorization is exact for a chosen sequence, but a graph is not naturally ordered. The same unlabeled graph can be produced through many node orderings and action histories.

### GraphRNN: turning a graph into a sequence of sequences

GraphRNN makes the construction explicit. It generates a graph by adding nodes and edges sequentially.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s05-image6.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GraphRNN construction of a graph by sequentially adding nodes and edges." caption="GraphRNN represents graph sampling as a sequence of local construction decisions. Reused from the 2025 ML4Mol molecular generation lecture, slide 5." %}

Choose a node ordering $$\pi$$. The ordered graph can then be mapped uniquely to a construction sequence $$S^\pi$$.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s06-image7.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph and node ordering mapped to a sequence of node and edge additions." caption="A graph plus a node ordering determines one sequential representation. Reused from the 2025 ML4Mol molecular generation lecture, slide 6." %}

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s06-image8.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Stepwise ordered graph construction showing nodes and edges appearing over time." caption="The construction history expands the graph according to the selected ordering. Reused from the 2025 ML4Mol molecular generation lecture, slide 6." %}

The representation has two nested levels. At the node level, a new node is appended.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s07-image9.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Node-level GraphRNN sequence adding one node at each step." caption="The outer sequence decides when each new node is introduced. Reused from the 2025 ML4Mol molecular generation lecture, slide 7." %}

At the edge level, the model decides which earlier nodes connect to that new node.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s08-image10.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Edge-level GraphRNN sequence connecting a newly added node to previous nodes." caption="For each new node, an inner sequence specifies its edges to the existing graph. Reused from the 2025 ML4Mol molecular generation lecture, slide 8." %}

The result is a sequence of sequences: an outer node sequence and one inner edge sequence per node.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s09-image11.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GraphRNN mapping from an ordered graph and adjacency matrix to nested node-level and edge-level sequences." caption="GraphRNN linearizes an ordered adjacency matrix into nested node and edge sequences. Reused from the 2025 ML4Mol molecular generation lecture, slide 9." %}

GraphRNN implements this hierarchy with two recurrent networks. A node-level RNN maintains the state of the graph and initializes an edge-level RNN. The edge-level RNN then emits the adjacency decisions for the new node.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s10-image12.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GraphRNN architecture with a node-level recurrent network controlling an edge-level recurrent network." caption="Two recurrent levels mirror the nested construction grammar. Reused from the 2025 ML4Mol molecular generation lecture, slide 10." %}

The ordering $$\pi$$ has so far been selected rather than learned as part of the graph identity. This is not just a cosmetic serialization choice: different orderings change the conditional distributions that the RNN must model.

### Tractability through breadth-first search

Without further restriction, a new node can connect to any earlier node. Generating $$n$$ nodes can therefore require the full lower triangle of an $$n\times n$$ adjacency matrix, with long dependencies in the edge sequence.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s11-image13.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph generation example illustrating the long edge sequence required under a random node ordering." caption="An arbitrary ordering can make each node's adjacency decision reach far back through the generated sequence. Reused from the 2025 ML4Mol molecular generation lecture, slide 11." %}

Breadth-first-search ordering reduces this burden. Nodes are visited by graph distance from a root, so edges tend to fall inside a band near the diagonal of the ordered adjacency matrix.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s12-image14.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Adjacency matrices without and with breadth-first-search ordering, showing a narrower dependency band." caption="BFS ordering limits how far back the edge-level generator usually needs to look. Reused from the 2025 ML4Mol molecular generation lecture, slide 12." %}

This does not remove ordering dependence; it chooses an ordering family whose sequence is easier to model.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s13-image16.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Colored adjacency matrix emitted by a neural graph generator." caption="The generator's output representation determines which constraints must be learned at the matrix level. Reused from the 2025 ML4Mol molecular generation lecture, slide 13." %}

For molecules, the alternatives include adjacency matrices, atom and bond motifs, and strings such as SMILES.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s14-representation-grammars.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Comparison of adjacency-matrix, motif, and string grammars for generating one molecular graph." caption="The same molecular graph can be constructed through matrix entries, chemical motifs, or a linearized string. Cropped from the 2025 ML4Mol molecular generation lecture, slide 14." %}

The grammar determines the action space, sequence length, validity constraints, and inductive bias. It also determines what the model cannot express without extending its vocabulary.

## Motifs, strings, and diffusion

### Motif- and fragment-based generation

Many molecular graphs can be decomposed into frequently occurring motifs or fragments, much as sentences are decomposed into words. Some chemically meaningful fragments are familiar functional groups.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s15-image17.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Molecules decomposed into recurring chemical fragments and functional groups." caption="A motif vocabulary promotes recurring subgraphs from many atomic actions into reusable construction units. Reused from the 2025 ML4Mol molecular generation lecture, slide 15." %}

Motif-by-motif generation replaces many node and edge updates with a smaller number of fragment attachment decisions. This is especially useful for large graphs such as polymers.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s16-image18.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Examples of large molecular and polymer graphs assembled from repeated fragments." caption="Large molecular structures often contain repeated subgraphs that can be generated as units. Reused from the 2025 ML4Mol molecular generation lecture, slide 16." %}

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s16-image19.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Molecule generated through successive additions of chemical motifs." caption="Motif generation advances through chemically meaningful fragment attachments rather than individual adjacency entries. Reused from the 2025 ML4Mol molecular generation lecture, slide 16." %}

The vocabulary is also a boundary. A fixed motif library cannot generate a genuinely new motif outside the represented training distribution, and extracting the motifs requires chemical knowledge or a decomposition algorithm.

### String-based generation

Programs can linearize a molecular graph into a string. SMILES—the simplified molecular-input line-entry system—is the leading example.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s17-image20.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Molecular graph with alternative highlighted SMILES traversals." caption="SMILES records a graph through a traversal with tokens for atoms, branches, bonds, and ring closures. {% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s17-image21.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Alternative SMILES rendering for the same molecular structure." caption="A molecular graph can admit multiple valid SMILES strings because the traversal is not unique. Reused from the 2025 ML4Mol molecular generation lecture, slide 17." %}

Once the graph is a string, an LSTM or Transformer can generate it with ordinary language-model machinery.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s18-image22.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="LSTM autoregressively generating a SMILES sequence that decodes to a molecule." caption="String generation converts molecular construction into next-token prediction. The convenience comes at the cost of explicit graph structure. Atoms adjacent in the molecule may be separated in the string, one graph has several serializations, and syntactically valid token sequences still need chemical validity.

### Diffusion models for graphs

Autoregressive generation commits to an ordering and a construction direction. A diffusion model instead generates all elements through a parallel denoising process, alleviating the node-ordering problem.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s19-image23.gif" class="img-fluid rounded z-depth-1" zoomable=true alt="Animated graph diffusion process evolving an adjacency representation from noise to a structured graph." caption="Graph diffusion denoises a whole graph representation rather than selecting one node-addition history. Reused from the 2025 ML4Mol molecular generation lecture, slide 19." %}

One approach relaxes the adjacency matrix into continuous variables. Gaussian noise corrupts the relaxed representation, and a neural network learns the reverse process.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s20-image24.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Continuous diffusion over relaxed adjacency matrices." caption="Continuous graph diffusion embeds discrete adjacency entries in a real-valued space for noising and denoising. Reused from the 2025 ML4Mol molecular generation lecture, slide 20." %}

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s20-image25.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Score-matching objectives for node and adjacency variables in a continuous graph diffusion model." caption="The reverse model predicts denoising fields for graph variables under the relaxed diffusion process. Reused from the 2025 ML4Mol molecular generation lecture, slide 20." %}

The adjacency matrix remains tied to a node labeling, but the denoising network can be permutation-equivariant and need not choose an autoregressive order.

A discrete diffusion model avoids the continuous relaxation. A corruption process directly masks or changes categorical node and edge states, and the learned reverse process restores them.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s21-image26.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Discrete graph diffusion progressively masking and reconstructing nodes and edges." caption="Discrete graph diffusion defines noising and denoising directly on categorical graph states. Reused from the 2025 ML4Mol molecular generation lecture, slide 21." %}

Continuous and discrete diffusion therefore attack the same ordering issue with different state spaces. The former gains familiar Gaussian machinery but must return to discrete validity; the latter preserves categorical semantics but needs a discrete transition process.

## Reaction and retrosynthesis prediction

Molecular generation proposes a target; synthesis asks how that target can be made. The lecture now changes direction from sampling structures to predicting chemical transformations.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s22-image27.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Overview of single-step and multistep retrosynthesis methods and evaluation." caption="Retrosynthesis connects a target structure to feasible precursors through single-step prediction and multistep planning. Reused from the 2025 ML4Mol molecular generation lecture, slide 22." %}

Reaction prediction maps reactants to a product. Retrosynthesis reverses the question: given a product, predict the reactants or precursors that could produce it.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s23-image28.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Forward reaction prediction and backward retrosynthetic prediction for the same chemical transformation." caption="Forward prediction resolves a product from reactants; retrosynthesis proposes precursors from a target product. Reused from the 2025 ML4Mol molecular generation lecture, slide 23." %}

The inverse is one-to-many. Several reagent sets and reaction families can lead to the same target, so retrosynthetic prediction should rank alternatives rather than pretend that the recorded literature route is uniquely correct.

### Template-based and template-free prediction

The simplest template-based approach predicts one transformation from a library of existing reaction templates. A template identifies the local bond changes and the chemical context in which they are applicable.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s24-image29.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Chemical reaction template applied to a target molecule to obtain retrosynthetic precursors." caption="Template-based retrosynthesis selects a known local transformation and applies it backward to the target. Reused from the 2025 ML4Mol molecular generation lecture, slide 24." %}

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s24-image31.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Neural ranking of candidate retrosynthesis templates and precursor sets." caption="A learned model ranks applicable transformation templates and their resulting reactants. Reused from the 2025 ML4Mol molecular generation lecture, slide 24." %}

Templates provide strong chemical structure but inherit the coverage of the extracted library.

Template-free methods formulate retrosynthesis as graph-to-graph(s) translation. The model identifies a reaction center, edits product bonds, and completes the resulting precursor graphs without choosing one named template.

### Root-aligned SMILES and model ensembles

SMILES language models can also perform reaction translation. Root-aligned SMILES reduces source–target mismatch by choosing reactant and product serializations that begin from corresponding atoms near the reaction center.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s26-image35.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Root-aligned SMILES examples with product and reactant strings beginning at corresponding atoms." caption="Root alignment chooses compatible SMILES traversals so that the translation model sees less artificial token reordering. Reused from the 2025 ML4Mol molecular generation lecture, slide 26." %}

The alignment changes the sequence problem without changing the underlying reaction. It is a representation-level intervention: more of the token correspondence now reflects chemistry rather than arbitrary traversal.

### Retrosynthesis for inorganic materials

Materials synthesis has a different grammar. ElemwiseRetro extracts precursor choices from the literature and learns to select them element by element for an inorganic target.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s28-image41.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="ElemwiseRetro formulation and neural architecture for selecting inorganic synthesis precursors." caption="ElemwiseRetro turns literature-derived material recipes into elementwise precursor-selection targets. Reused from the 2025 ML4Mol molecular generation lecture, slide 28." %}

The formulation reflects the domain. Organic retrosynthesis often centers on local bond disconnections; inorganic synthesis must reason about precursor sets, stoichiometry, and processing conditions for a target composition or phase.

## Multistep retrosynthetic planning

A single retrosynthetic step is not a synthesis plan. Each proposed precursor may itself be unavailable and require another disconnection. Recursive expansion produces a tree whose leaves should be purchasable or otherwise acceptable starting materials.

Neural-guided tree search alternates three operations: select a promising frontier node, expand it with a one-step retrosynthesis model, and update values through the search tree.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s29-image42.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Retrosynthesis tree search with iterative selection, expansion, and value updates." caption="Multistep planning uses a one-step model inside a search procedure that builds complete routes. Reused from the 2025 ML4Mol molecular generation lecture, slide 29." %}

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s29-image43.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Header for neural-guided A-star retrosynthesis planning." caption="A learned policy and value function can guide A*-style search toward promising synthetic routes. Reused from the 2025 ML4Mol molecular generation lecture, slide 29." %}

The search objective must balance more than the local probability of a reaction. Route length, precursor availability, predicted yield, safety, and model uncertainty can all affect which branch is worth expanding.

An alternative asks a neural network to generate the entire sequence of retrosynthetic steps end to end.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s30-image44.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="End-to-end generation of a multistep retrosynthetic route from target molecule to precursors." caption="End-to-end route generation emits a complete sequence of disconnections instead of invoking a separate tree-search loop. Reused from the 2025 ML4Mol molecular generation lecture, slide 30." %}

This compresses planning into one generative model but also concentrates failure: an early invalid step changes the context for every later prediction, and the model must represent the branching alternatives that explicit search keeps visible.

### Scaling through unformatted, multi-task data

Conventional models often learn from one formatted dataset per task: a retrosynthesis table, a molecule-generation corpus, or a property-prediction benchmark. Language models can ingest unformatted literature containing all of these forms together.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s33-task-data-scaling.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Comparison between separate task-specific chemistry models and one language model trained on unformatted multi-task literature." caption="The proposed scaling advantage of LLMs is access to unformatted, multi-task scientific data rather than only larger versions of one benchmark. Cropped from the 2025 ML4Mol molecular generation lecture, slide 33." %}

The data are easier to collect at scale, but their supervision is indirect. Papers report successful experiments selectively, use inconsistent notation, and mix claims with hypotheses. More tokens do not automatically provide a balanced reaction database or verified physical labels.

The shared interface is powerful because one architecture can accept several kinds of prompt. Its chemistry still depends on how molecular strings, reaction components, and textual conditions are represented and aligned.

### Chemeleon: text-guided material generation

Chemeleon generates materials from text with a CLIP-like objective. A text encoder and a crystal encoder learn a shared space, allowing textual descriptions to guide crystal generation.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/ml4mol-2025-09/s35-image59.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Chemeleon text-guided material generation through aligned text and crystal representations." caption="Chemeleon aligns natural-language material descriptions with crystal representations for conditional generation. This extends molecular text generation into periodic structure. A phrase such as a composition, prototype, or property cue must ultimately constrain lattice and atomic variables, so the text alignment is only the conditioning interface to a geometric generator.

This final step does not replace the earlier representations; it sits above them. Graph grammars define valid molecular construction, reaction models define transformations, planners compose steps, and literature-trained language models connect these tools to unformatted scientific knowledge. The lecture's storyline is therefore cumulative. Scaling text is valuable precisely when the model can still ground its output in molecular graphs, reaction structure, and executable synthesis plans.
