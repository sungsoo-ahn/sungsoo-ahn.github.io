## From graph functions to graph discrimination

A graph combines a vertex set, edge set, node features, and possibly edge features. Its stored indices are arbitrary, so a graph representation must be interpreted together with the permutation action on those objects.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s04-graph-representations.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph, adjacency-matrix, feature-matrix, and tensor representations of the same attributed graph." caption="Graph structure and node features admit several equivalent tensor representations. Original PowerPoint figure from slide 4." %}

For $$n=|V|$$, the usual representation stores $$A\in\mathbb R^{n\times n}$$ and $$X\in\mathbb R^{n\times d}$$ separately. A tensorial alternative uses $$\mathcal X\in\mathbb R^{n\times n\times d}$$, placing node features on diagonal entries and connectivity-dependent features off diagonal.

A graph neural network is a parameterized function on graphs. Depending on the target, it can return graph-, node-, or edge-level outputs while respecting the corresponding permutation action.

For a graph-level task, the lecture writes this simply as

$$
f_\Theta:\mathcal G\longrightarrow\mathbb R^\ell,
$$

where $$\mathcal G$$ denotes attributed graphs, $$\Theta$$ the learnable parameters, and $$\mathbb R^\ell$$ the graph representation or prediction space.

Message-passing networks repeatedly aggregate information from neighborhoods. Their shared local update is permutation-equivariant, and a symmetric readout can produce a graph-invariant representation.

$$
f_\Theta=\rho\circ\mu^{(L)}\circ\cdots\circ\mu^{(1)},
$$

with a layer written in either global or node-wise form as

$$
x_v^{(l+1)}=\mu^{(l)}(A,X)_v
=\operatorname{upl}^{(l)}\!\left(
x_v^{(l)},
\sum_{w\sim v}\operatorname{msg}^{(l)}
\big(x_v^{(l)},x_w^{(l)}\big)
\right).
$$

The graph representation pools the final node states,

$$
h_G=\rho\big(\{x_v^{(L)}\mid v\in V\}\big)
=\psi\left(\sum_{v\in V}x_v^{(L)}\right).
$$

### Isomorphism as an expressivity test

Two graphs are isomorphic if there is a bijection $$\varphi:V\to V'$$ that preserves adjacency and features. The central expressivity question is how many pairs of non-isomorphic graphs a GNN can distinguish.

For attributed graphs $$(V_1,E_1,X_1)$$ and $$(V_2,E_2,X_2)$$, the conditions are

$$
(u,v)\in E_1
\quad\Longleftrightarrow\quad
(\varphi(u),\varphi(v))\in E_2,
\qquad
(X_1)_u=(X_2)_{\varphi(u)}.
$$

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s07-graph-isomorphism.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A vertex bijection preserving adjacency and node features between two graph representations." caption="Graph isomorphism preserves adjacency and features under a vertex bijection. Original PowerPoint figure from slide 7." %}

MPNNs give the same graph representation to isomorphic inputs. Their updates commute with relabeling, so the representation is faithful to the equivalence that should not change a graph-level prediction.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s08-isomorphic-commuting-diagram.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A commuting diagram showing two isomorphic graphs mapped to the same graph representation." caption="Permutation equivariance makes the MPNN representation invariant to graph relabeling. Original PowerPoint figure from slide 8." %}

The converse fails. Distinct graphs can collapse to the same MPNN representation, so permutation validity does not imply injective representation of graph isomorphism classes.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s09-representation-collapse.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Several non-isomorphic graph classes collapsing to the same learned representation and downstream prediction." caption="Permutation validity does not prevent non-isomorphic graphs from colliding in representation space. Original PowerPoint figure from slide 9." %}

Regular graphs make the limitation concrete. When all vertices begin with the same feature and have the same degree, local multisets can remain identical at every layer. Circular skip-link graphs provide abstract examples; molecular graphs such as decalin and bicyclopentyl illustrate that the collision is not confined to toy networks.

### Approximation depends on discrimination

For Euclidean inputs, universal approximation describes which continuous functions an MLP can approximate. The graph analogue must first account for the fact that the input domain is partitioned into isomorphism classes.

On a compact Euclidean domain, the familiar statement has the form

$$
\forall g:\mathcal X\to\mathbb R^d,\ \forall\varepsilon>0,
\quad \exists f\in\mathcal N
\quad\text{such that}\quad
\lVert g-f\rVert<\varepsilon.
$$

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s11-universal-approximation.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A continuous target function and an approximating neural-network hypothesis within epsilon." caption="Universal approximation asks whether a model class can approach every continuous target arbitrarily closely. Original PowerPoint figure from slide 11." %}

Let $$\mathcal C$$ be the continuous invariant graph functions and let $$\mathcal M$$ be the functions representable by an MPNN. A representation that maps two non-isomorphic graphs to the same point cannot approximate an invariant target that assigns them different values.

Under the usual compactness and closure assumptions, the lecture expresses the bridge succinctly: an invariant function class is universally approximating exactly when it distinguishes every pair of non-isomorphic graphs in its domain. Discrimination is therefore not merely a diagnostic; it is a necessary part of graph-function approximation.

The MPNN function class is therefore a strict subset of all continuous invariant graph functions whenever its representation has non-isomorphic collisions.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s13-function-class-inclusion.png" class="img-fluid rounded z-depth-1" zoomable=true alt="The MPNN function class drawn as a strict subset of invariant graph functions." caption="MPNNs cover only the invariant functions that are constant on their graph-representation collisions. Original PowerPoint figure from slide 13." %}

Counting an induced subgraph is one excluded target. An induced subgraph on a vertex subset retains every edge of the original graph between those vertices, and ordinary MPNNs cannot in general count such patterns.

For $$V_S\subseteq V$$, the induced subgraph is

$$
S=G[V_S]=\big(V_S,\ E\cap V_S^2\big).
$$

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s14-substructure-function-class.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Ring-counting functions shown outside the MPNN function class." caption="Induced-substructure counts are invariant functions that ordinary message passing cannot always represent. Original PowerPoint figure from slide 14." %}

This leaves two linked questions: how should GNN expressivity be quantified, and how can architectures exceed the MPNN ceiling?

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s15-expressivity-gap.png" class="img-fluid rounded z-depth-1" zoomable=true alt="The gap between MPNN functions and the larger class of invariant graph functions." caption="More expressive architectures aim to fill graph distinctions left outside the MPNN class. ## The Weisfeiler--Lehman hierarchy

The graph-isomorphism problem is neither known to have a polynomial-time solution nor known to be NP-complete. It is sometimes informally described as “intermediate,” as in the source slide, but that is not a proved complexity classification. The Weisfeiler--Lehman test is a combinatorial heuristic: if it distinguishes two graphs, they are non-isomorphic; failure to distinguish them is inconclusive. GNN expressivity is commonly placed relative to this hierarchy.


### Color refinement

One-dimensional WL initializes a color for every node, usually from its attributes or a common label.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s17-wl-initialization.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Two graphs receiving the same initial WL color before refinement." caption="One-dimensional WL begins from node labels or a common initial color. Original PowerPoint figure from slide 17." %}

At each round, it collects the multiset of neighboring colors.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s18-wl-neighborhoods.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Two graphs after a WL update with neighbor-color multisets and color histograms." caption="A WL round refines each color from the current color and the multiset of neighbor colors. Original PowerPoint figure from slide 18." %}

It hashes the current color and neighborhood multiset into a refined color, then repeats until the partition stabilizes.

For each graph $$G$$, the update is

$$
c_{v,G}^{(t)}=operatorname{HASH}\!\left(
c_{v,G}^{(t-1)},
\left\{\!\left\{c_{w,G}^{(t-1)}\mid w\in N_G(v)\right\}\!\right\}
\right).
$$

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s19-wl-stable-coloring.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Stable WL colorings and equal color histograms for two graphs." caption="If stable color histograms remain equal, one-dimensional WL reaches no isomorphism conclusion. Original PowerPoint figure from slide 19." %}

If the two graphs have different color histograms at any iteration, WL distinguishes them. The update has the same structural form as an MPNN: aggregate a multiset and transform the result.


Not every MPNN matches 1-WL. GIN was designed to do so: sum aggregation counts colors, while an MLP approximates the injective hash. Mean or max aggregation can collapse multisets that 1-WL keeps distinct.

The GIN update shown in the lecture is

$$
x_v^{(t)}=\psi^{(t)}\!\left(
(1+\epsilon^{(t)})x_v^{(t-1)}
+\sum_{w\in N(v)}x_w^{(t-1)}
\right).
$$

By contrast, a GCN-style normalized average has the form

$$
x_v^{(t)}=\phi^{(t)}\!\left(
\sum_{w\in N(v)\cup\{v\}}
\frac{x_w^{(t-1)}}{
\sqrt{|N(v)\cup\{v\}|\,|N(w)\cup\{w\}|}}
\right),
$$

which need not preserve multiset multiplicities injectively.


Higher-order GNNs seek stronger tests by representing tuples rather than single vertices.


The common construction recipe is explicit: define a stronger WL variant, then design a neural architecture able to simulate that test.


### The k-WL test

The $$k$$-WL test colors ordered $$k$$-tuples $$\mathbf v=(v_1,\ldots,v_k)$$ rather than individual vertices. It considers tuples from $$V^k$$, including pairs that are not edges, so the computational state grows from $$|V|$$ nodes to $$|V|^k$$ tuples.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s24-k-tuple-space.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A matrix-like view of ordered vertex pairs including edges and nonedges." caption="Higher-order WL colors all ordered tuples, not only edges. Original PowerPoint figure from slide 24." %}

For each coordinate position, it replaces that coordinate by every possible vertex, collects the resulting tuple colors, and hashes the collection into a new color.

Let $$\phi_j(\mathbf v,w)$$ replace coordinate $$j$$ of $$\mathbf v$$ by $$w$$. One refinement round is

$$
C_{i+1}(\mathbf v)=\operatorname{HASH}\big(C_i(\mathbf v),M_i(\mathbf v)\big),
$$

where

$$
M_i(\mathbf v)=\left(
\left\{\!\left\{C_i(\phi_1(\mathbf v,w))\mid w\in V\right\}\!\right\},
\ldots,
\left\{\!\left\{C_i(\phi_k(\mathbf v,w))\mid w\in V\right\}\!\right\}
\right).
$$

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s25-k-coordinate-neighborhood.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A highlighted row and column representing coordinate-replacement neighborhoods for an ordered pair." caption="For a pair, replacing one coordinate sweeps a row or column of the tuple space. Original PowerPoint figure from slide 25." %}

Initialization must already encode graph structure. Two tuples receive the same initial color exactly when the coordinate mapping between them induces the same equality and adjacency pattern.

Equivalently, the initial color records the isomorphism type of the labeled induced subgraph on the tuple coordinates, including repeated-coordinate information. This is why nonedges appear in the state space even though ordinary message passing only traverses edges.


For $$k\ge2$$, increasing tuple order strictly strengthens the hierarchy, and sufficiently high order can separate all graphs of a fixed size. The corresponding $$k$$-GNNs mimic this tuple refinement.

A corresponding linear higher-order update takes the form

$$
f_{\mathbf v}^{(t)}=
W_1 f_{\mathbf v}^{(t-1)}
+W_2\sum_{\mathbf u\in N(\mathbf v)}f_{\mathbf u}^{(t-1)},
$$

where the neighborhood is defined in tuple space. Papers use slightly different offsets between “$$k$$-GNN” and “$$k$$-WL” terminology; the substantive statement is that the architecture simulates its associated tuple-refinement test.


The guarantee is purchased with large neighborhoods and $$|V|^k$$ states. A provable expressivity hierarchy is therefore also a computational hierarchy.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s28-wl-gnn-hierarchy.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A hierarchy aligning GNN, 2-GNN, 3-GNN, and k-GNN levels with WL tests." caption="The higher-order GNN hierarchy tracks the corresponding WL hierarchy, with indexing conventions stated in the text. Original PowerPoint figure from slide 28." %}

The lecture's main storyline follows successive sparsifications: the original $$k$$-GNN mimics $$k$$-WL, local variants reduce neighborhoods, and sparsity-aware variants reduce the tuple set itself. In each case, the neural design follows the new combinatorial test.


## Sparse and invariant higher-order models

The $$\delta$$-$$k$$-WL family introduces sparse connectivity into higher-order refinement and supplies a corresponding neural architecture.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s30-sparse-wl-hierarchy.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Expressive-power relations among k-WL, local WL variants, invariant graph networks, and sparse higher-order GNNs." caption="WL Go Sparse reorganizes the higher-order hierarchy around local tuple neighborhoods. Original PowerPoint figure from slide 30." %}

The local test replaces full coordinate substitutions by graph-local ones. Tuple-neighborhood size is bounded by graph degree rather than the full vertex count.

Its local neighborhood representation is

$$
M_i^\delta(\mathbf v)=\left(
\left\{\!\left\{C_i(\phi_1(\mathbf v,w))\mid w\in N(v_1)\right\}\!\right\},
\ldots,
\left\{\!\left\{C_i(\phi_k(\mathbf v,w))\mid w\in N(v_k)\right\}\!\right\}
\right),
$$

so its size is controlled by $$k\max_v|N(v)|$$ rather than $$k|V|$$.


The enhanced local variant adds counts of globally occurring colors to recover information lost by localizing the neighborhood. It makes the efficiency--expressivity compromise explicit rather than assuming locality is free.

For every locally reached replacement $$\phi_j(\mathbf v,w)$$, the “plus” variant also attaches the number of global coordinate replacements that share its current color. Those multiplicities retain global color information without explicitly materializing the full neighborhood.

The result highlighted on the source slide is that $$\delta$$-$$k$$-LWL$$^+$$ is strictly stronger than the corresponding full-neighborhood $$k$$-WL variant used in that comparison.


The corresponding $$\delta$$-$$k$$-LGNN implements these local refinement rules in a neural architecture.

Writing $$\delta(\mathbf v)$$ for the local tuple neighborhoods, the shared neural update has the schematic form

$$
f^{(t)}(\mathbf v)=
f_{\mathrm{mrg}}^{W_1}\!\left(
f^{(t-1)}(\mathbf v),
f_{\mathrm{agg}}^{W_2}\!\left(
\left\{\!\left\{f^{(t-1)}(\phi_j(\mathbf v,w))
\mid w\in\delta(v_j)\right\}\!\right\}_{j=1}^k
\right)
\right).
$$

With injective aggregation and merge functions, $$\delta$$-$$k$$-LGNN has the same distinguishing power as $$\delta$$-$$k$$-LWL; the lecture records an analogous correspondence for the plus variant.


SpeqNets address the remaining $$|V|^k$$ tuple count. Their $$(k,s)$$-LWL construction keeps only tuples whose induced connectivity satisfies a prescribed sparsity condition.

The retained tuple set is

$$
V(G)_s^k=
\left\{\mathbf v\in V(G)^k\ \middle|\
\#\operatorname{com}(G[\mathbf v])\le s
\right\},
$$

where $$\#\operatorname{com}$$ counts connected components of the induced subgraph on the tuple entries. Neighborhood replacements are accepted only when the resulting tuple remains in this set.


Changing the allowed tuple family changes both memory and which graph distinctions remain accessible.


Faster variants are progressively less expressive. The source treats this as a structured tradeoff rather than a single architecture ranking.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s36-speqnet-hierarchy.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A hierarchy showing SpeqNet sparsity levels, WL variants, and increasing function classes." caption="SpeqNets trade tuple sparsity against the set of invariant functions they can approximate. Original PowerPoint figure from slide 36." %}

Invariant Graph Networks take a different route. They characterize permutation-equivariant linear layers on high-order tensors and, with nonlinearities, inherit universal-approximation results for continuous invariant hypergraph functions.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s37-ign-equivariance.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A matrix-valued feature transformed before and after an equivariant linear map." caption="Invariant Graph Network layers commute with the simultaneous permutation of tensor indices. Original PowerPoint figure from slide 37." %}

The lecture places IGNs relative to WL: second-order invariant networks are bounded by corresponding WL variants, while sufficiently structured higher-order networks can simulate them.

The lecture records three theoretical landmarks:

| Statement | Consequence |
| --- | --- |
| Sufficiently high-order invariant hypergraph networks can approximate any continuous invariant hypergraph function | Universality is possible, but the required tensor order can grow polynomially with graph size |
| Higher-order IGNs can simulate corresponding WL refinements | The tensor architecture has a combinatorial lower bound on its discrimination power |
| Their power is also upper-bounded by an associated WL level | Tensor order does not remove the hierarchy; it locates the model within it |


The next family moves from tuple order to explicit graph structures: substructure-aware models attach counts or lift the input into richer combinatorial objects.


At this pivot, the lecture contrasts higher-order GNNs—permutation invariant, hierarchically expressive, and polynomial but expensive—with node-identifier approaches that can be linear-cost and universal only in expectation.

## Structural encodings and cellular lifts

Substructure counts offer equivariant node identification without arbitrary random IDs. They can encode strong domain priors, capture information unavailable to MPNNs, and remain compatible with permutation.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s41-substructure-node-identification.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A molecular graph with a highlighted ring and local branch used as structural node identifiers." caption="Substructures identify nodes through graph structure rather than arbitrary external labels. Original PowerPoint figure from slide 41." %}

The recipe chooses a bank $$\mathcal H$$ of motifs, matches each motif throughout the input graph, and augments every node with the number of matches in which it participates.

Formally, matching maps a substructure into the graph while preserving the relevant adjacency pattern. Node-level encodings count embeddings or induced embeddings whose image contains that node.

For a motif $$H=(V_H,E_H)$$ and a selected subgraph $$S=(V_S,E_S)$$ of $$G$$, a substructure isomorphism $$\varphi:V_H\to V_S$$ is a bijection preserving adjacency. An induced match additionally preserves non-adjacency. The encoding $$x_v^{\mathcal H}$$ counts, motif by motif, the valid matches whose image contains $$v$$.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s44-substructure-matching.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Subgraph and induced-subgraph isomorphisms from a motif into a larger molecular graph." caption="Induced matching preserves both adjacency and non-adjacency among matched vertices. Original PowerPoint figure from slide 44." %}

Graph Substructure Networks combine these encodings with an MPNN. They are strictly stronger than ordinary MPNNs when the motif bank contains non-star patterns, and induced patterns with at least three vertices can already add distinguishing power. With sufficiently rich preprocessing, the construction can become universal.

The GSN layer used in the lecture makes the structural counts explicit inputs to the message function:

$$
x_v^{(l+1)}=operatorname{upl}_l\!\left(
x_v^{(l)},
\sum_{w\sim v}
\operatorname{msg}_l\!\left(
x_v^{(l)},x_w^{(l)},x_v^{\mathcal H},x_w^{\mathcal H}
\right)
\right).
$$


On ZINC-12k, the source compares both predictive accuracy and generalization as the number and type of counted structures change.

The lecture summarizes structural encodings by three axes: expressive gain, computational complexity, and permutation symmetry. Random node identifiers, positional encodings, motif counts, and higher-order features occupy different points in this space.

| Structural encodings | Consequence |
| --- | --- |
| Expressive and permutation invariant | The added features can separate graphs while respecting relabeling |
| Linear-cost message passing after preprocessing | The expensive motif matching occurs before the learned layers |
| Motif-bank design | Domain knowledge determines what structures become visible |
| Rigid matching | Small motif changes may be treated as categorically different |
| Necessarily node-wise in this construction | A graph-level motif count must be distributed back to node features |


### Lifting graphs into cellular complexes

A cellular complex generalizes a graph with higher-dimensional cells while requiring intersections of cells to remain cells. It can encode vertices, edges, filled cycles, and larger regions as separate objects.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s48-cellular-complex.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A set lifted to a graph and then to a two-dimensional cellular complex through gluing maps." caption="Cellular complexes make higher-dimensional cells and their boundary relations explicit. Original PowerPoint figure from slide 48." %}

Lifting maps a graph to a complex before message passing. A skeleton-preserving lift leaves the original vertices and edges intact, guaranteeing that the representation does not fall below the 1-WL baseline while adding cells for structures such as cycles.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s49-complex-lifts.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Clique and ring lifts turning selected graph patterns into higher-dimensional cells." caption="Skeleton-preserving lifts add cells for cliques or rings without deleting the original graph. Original PowerPoint figure from slide 49." %}

CW Networks pass messages among incident cells. With $$k$$-ring or $$k$$-clique lifts for $$k\ge3$$, the lecture states that they are strictly more powerful than MPNNs. For $$k\ge4$$, the corresponding construction is not less powerful than the cited 3-WL baseline.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s50-cwn-message-passing.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Messages passed between a cell and its boundary and co-boundary cells." caption="CW Networks exchange messages across incident cells in a lifted complex. | CIN | **0.115 ± 0.003** | **0.079 ± 0.006** | **0.022 ± 0.002** | **80.94 ± 0.57** |


Placed in context, substructure-aware message passing can modify initial node features, change the domain through preprocessing, or alter the message-passing objects themselves. GSNs and CWNs do not add structure at the same stage.


The lecture then turns to subgraph GNNs, which run a shared model over a bag of derived subgraphs rather than adding only a fixed count or cell lift.


The second recap locates three families: higher-order tensor models, substructure-aware encodings and complexes, and MPNNs with identifiers. Subgraph GNNs combine aspects of identification and repeated structured views.

| Family | Formal advantages | Practical limitations |
| --- | --- | --- |
| Higher-order GNNs | Permutation invariant; hierarchical expressiveness; polynomial complexity for fixed order | Often intractable at useful tuple order |
| Substructure-aware GNNs | Permutation invariant; linear learned layers after preprocessing | Require motif/domain design and preprocessing |
| MPNNs with node identifiers | Invariant and potentially universal in expectation; linear message passing | Can be hard to train, tune, and generalize |


## Subgraph GNNs and their symmetry limits

The motivating observation is that two whole graphs can be WL-equivalent even when their derived subgraphs are distinguishable by WL. A graph can therefore be represented as a bag of views, each exposing a different local or perturbed structure.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s55-subgraph-intuition.png" class="img-fluid rounded z-depth-1" zoomable=true alt="WL-equivalent graphs whose node-deleted subgraphs have different WL color histograms." caption="Derived subgraphs can expose distinctions that remain invisible on the original graphs. Original PowerPoint figure from slide 55." %}

The aim is a model that remains tractable, equivariant, and domain-agnostic while becoming strictly more expressive than ordinary MPNNs.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s56-subgraph-gnn.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A graph transformed by a selection policy into a bag of subgraphs and processed by an equivariant layer." caption="A subgraph GNN applies a shared encoder to a systematically constructed bag of graph views. Original PowerPoint figure from slide 56." %}

A subgraph GNN has three components: a policy that selects or constructs subgraphs, an encoder shared across the bag, and an invariant or equivariant aggregation that combines their representations.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s57-subgraph-components.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A subgraph selection policy, a bag of graph views, and a shared encoder." caption="Selection, within-view encoding, and across-view aggregation are separate architectural choices. Original PowerPoint figure from slide 57." %}

Node-based policies create one view per original node. Common choices take an ego network, mark the selected node, or delete it. This one-to-one correspondence gives the bag an additional node-indexed structure.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s58-ego-subgraphs.png" class="img-fluid rounded z-depth-1" zoomable=true alt="One ego-network rooted at each node of a graph." caption="A node-based policy creates one indexed subgraph view per original vertex. Original PowerPoint figure from slide 58." %}

DS-GNN, reconstruction-based GNNs, and nested GNNs differ in how these views are selected and how their node and subgraph features are aggregated.

For view $$i$$ with adjacency $$A^i$$ and features $$X^{i,(t)}$$, the shared within-view encoder is

$$
X^{i,(t+1)}=\gamma_t\big(A^i,X^{i,(t)}\big).
$$

DS-GNN commonly uses node or edge deletion, reconstruction-based models use larger deletion sets, and nested GNNs use ego networks. The equation is shared; the policy determines which views exist.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s59-subgraph-policies.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Node deletion, k-node deletion, and ego-network policies feeding shared message-passing encoders." caption="DS-GNN, reconstruction GNNs, and nested GNNs differ primarily in their view policy and aggregation. Original PowerPoint figure from slide 59." %}

DS-GNN—also called Equivariant Subgraph Aggregation Networks—supports several selection policies and is provably more expressive than 1-WL.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s60-ds-gnn.png" class="img-fluid rounded z-depth-1" zoomable=true alt="The DSS-GNN architecture with equivariant subgraph layers, per-subgraph pooling, and set encoding." caption="DS-GNN processes several selected subgraphs with shared equivariant layers before invariant aggregation. Original PowerPoint figure from slide 60." %}

GNN-AK views an ordinary MPNN as a kernel operating on star neighborhoods and replaces the star with a richer induced subgraph around each node.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s61-gnn-ak-context.png" class="img-fluid rounded z-depth-1" zoomable=true alt="GNN-AK context aggregation across ego subgraphs and their node embeddings." caption="GNN-AK lets each node combine its representations across several centered subgraphs. Original PowerPoint figure from slide 61." %}

Its distinctive update lets node $$j$$ receive an embedding computed inside the subgraph centered at node $$i$$, creating interactions across the node and subgraph axes.

The source writes the within-subgraph embedding and fused center update as

$$
H^{i,(t)}=\gamma_t\big(A^i,X^{i,(t)}\big),
$$

$$
x_i^{i,(t+1)}=\phi\!\left(
h_i^{i,(t)},
\sum_j h_i^{j,(t)},
\sum_j h_j^{i,(t)}
\right).
$$

The second sum compares node $$i$$ across centered subgraphs; the third summarizes other nodes inside the subgraph centered at $$i$$.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s62-gnn-ak-pipeline.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Extraction, base-GNN convolution, and aggregation stages of GNN-AK." caption="GNN-AK replaces a star-neighborhood kernel with richer induced subgraph computations. Original PowerPoint figure from slide 62." %}

### The symmetry of a bag of subgraphs

Because node-based subgraphs are indexed by original nodes, permuting the graph also permutes the view axis. The node and subgraph indices are coupled by one permutation rather than acted on by independent groups.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s63-node-bag-symmetry.png" class="img-fluid rounded z-depth-1" zoomable=true alt="A node-based subgraph tensor with one coupled permutation compared with a generic bag with two independent permutations." caption="Node and subgraph axes in a node-based bag transform together under the original graph permutation. Original PowerPoint figure from slide 63." %}

This symmetry analysis places node-based subgraph GNNs below third-order Invariant Graph Networks and therefore below 3-WL. The extra views beat 1-WL, but they do not remove every higher-order ceiling.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s64-expressiveness-landscape.png" class="img-fluid rounded z-depth-1" zoomable=true alt="An expressiveness line placing node-based subgraph GNNs above 1-WL models and below 3-WL and 3-IGN." caption="Node-based subgraph GNNs lie between ordinary message passing and the third-order upper bound. Original PowerPoint figure from slide 64." %}

The natural next question is whether a modified bag construction can go beyond that upper bound.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s65-beyond-3wl.png" class="img-fluid rounded z-depth-1" zoomable=true alt="The expressiveness landscape extended with node-tuple policies and stronger base encoders." caption="Higher-order markings or stronger base encoders can move beyond the node-based 3-WL ceiling. Original PowerPoint figure from slide 65." %}

Ordered Subgraph Aggregation Networks mark ordered tuples of vertices rather than relying only on one-node subgraph operations. The order $$k$$ controls how much identifying structure is exposed.

If $$t_i$$ is the ordered tuple defining view $$i$$ and $$\operatorname{atp}(v,t_i)$$ is the atomic type of vertex $$v$$ relative to that tuple, initialization and propagation are

$$
x_v^{i,(0)}=\gamma_0\big(\operatorname{atp}(v,t_i)\big),
\qquad
X^{i,(t+1)}=\gamma_t\big(A^i,X^{i,(t)}\big).
$$

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s66-k-osan.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Ordered k-vertex markings followed by shared aggregation and message passing." caption="k-OSAN exposes ordered marked tuples before applying a shared graph encoder. Original PowerPoint figure from slide 66." %}

The expressivity result is nuanced. One-OSAN captures DS-GNN and GNN-AK. In general, $$k$$-OSAN is strictly weaker than $$(k+2)$$-WL, while $$k$$-OSAN and $$(k+1)$$-WL are incomparable.

For $$k=1$$, this means that 1-OSAN is strictly weaker than 3-WL, yet neither 1-OSAN nor 2-WL dominates the other. Ordered subgraph aggregation is therefore a different hierarchy, not merely WL with its level shifted by one.


Subgraph GNNs are attractive because they are equivariant, domain-agnostic, and tractable under restricted node-based policies. They are not an ultimate answer: large graphs make the bag expensive, and increasing $$k$$ raises the upper bound at exponential cost.

The lecture's final balance sheet is deliberately mixed:

| Benefit | Limitation |
| --- | --- |
| Exact equivariance under systematic policies | Many views must be encoded for every input graph |
| No hand-designed motif bank is required | Memory and runtime can be prohibitive on large graphs |
| Node-based policies can remain tractable | Raising tuple order $$k$$ incurs exponential growth |


The lecture ends by questioning a constraint shared by the entire storyline: exact permutation equivariance. Exact equivariance prevents false negatives in an isomorphism test, but one can instead present graph elements as tokens and learn the symmetry from data. TokenGT illustrates this route and is provably as expressive as a second-order invariant network.

{% include figure.liquid loading="lazy" path="assets/img/blog/lectures/gdl-2025-05/s69-tokengt.png" class="img-fluid rounded z-depth-1" zoomable=true alt="Node and edge tokens with type and orthonormal identifiers passed through a Transformer encoder." caption="TokenGT learns permutation behavior from tokenized graph elements rather than enforcing it in every layer. Original PowerPoint figure from slide 69." %}

The source's progression is therefore not a search for one universally expressive GNN. It is a sequence of choices about the represented object—nodes, tuples, motifs, cells, bags, or ordered markings—and the symmetry, preprocessing, memory, and runtime attached to that choice.
