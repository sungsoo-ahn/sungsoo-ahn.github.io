## From graph functions to graph discrimination

A graph combines a vertex set, edge set, node features, and possibly edge features. Its stored indices are arbitrary, so a graph representation must be interpreted together with the permutation action on those objects.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-4.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph with adjacency and node-feature representations." caption="Graphs combine relational structure and features while admitting arbitrary vertex indexing. Cropped from the 2025 GDL GNN-expressivity lecture, slide 4." %}

A graph neural network is a parameterized function on graphs. Depending on the target, it can return graph-, node-, or edge-level outputs while respecting the corresponding permutation action.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-5.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Parameterized invariant and equivariant functions on graph inputs." caption="A GNN maps a graph representation to outputs with the permutation behavior required by the task. Cropped from the 2025 GDL GNN-expressivity lecture, slide 5." %}

Message-passing networks repeatedly aggregate information from neighborhoods. Their shared local update is permutation-equivariant, and a symmetric readout can produce a graph-invariant representation.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-6.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Message-passing neural network update and graph readout." caption="MPNNs build graph representations by local aggregation followed by a symmetric readout. Cropped from the 2025 GDL GNN-expressivity lecture, slide 6." %}

### Isomorphism as an expressivity test

Two graphs are isomorphic if there is a bijection $$\varphi:V\to V'$$ that preserves adjacency and features. The central expressivity question is how many pairs of non-isomorphic graphs a GNN can distinguish.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-7.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graph isomorphism mapping between two vertex-indexed graphs." caption="Graph discrimination uses isomorphism as the equivalence relation that a valid representation must respect. Cropped from the 2025 GDL GNN-expressivity lecture, slide 7." %}

MPNNs give the same graph representation to isomorphic inputs. Their updates commute with relabeling, so the representation is faithful to the equivalence that should not change a graph-level prediction.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-8.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Commuting diagram for MPNNs on isomorphic graphs." caption="Permutation equivariance ensures that isomorphic graphs remain indistinguishable after message passing. Cropped from the 2025 GDL GNN-expressivity lecture, slide 8." %}

The converse fails. Distinct graphs can collapse to the same MPNN representation, so permutation validity does not imply injective representation of graph isomorphism classes.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-9.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Non-isomorphic graphs mapped to the same MPNN representation." caption="Some non-isomorphic graphs are indistinguishable to every ordinary MPNN. Cropped from the 2025 GDL GNN-expressivity lecture, slide 9." %}

Regular graphs make the limitation concrete. When all vertices begin with the same feature and have the same degree, local multisets can remain identical at every layer. Circular skip-link graphs provide abstract examples; molecular graphs such as decalin and bicyclopentyl illustrate that the collision is not confined to toy networks.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-10.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Regular graph collisions including CSL and molecular examples." caption="Regular graphs with the same size can defeat MPNNs because every node receives the same local evidence. Cropped from the 2025 GDL GNN-expressivity lecture, slide 10." %}

### Approximation depends on discrimination

For Euclidean inputs, universal approximation describes which continuous functions an MLP can approximate. The graph analogue must first account for the fact that the input domain is partitioned into isomorphism classes.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-11.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Universal approximation of continuous Euclidean functions by MLPs." caption="Universal approximation motivates an analogous function-class question for graph networks. Cropped from the 2025 GDL GNN-expressivity lecture, slide 11." %}

Let $$\mathcal C$$ be the continuous invariant graph functions and let $$\mathcal M$$ be the functions representable by an MPNN. A representation that maps two non-isomorphic graphs to the same point cannot approximate an invariant target that assigns them different values.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-12.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Connection between graph discrimination and invariant function approximation." caption="Graph approximation power is limited by which isomorphism classes the representation can separate. Cropped from the 2025 GDL GNN-expressivity lecture, slide 12." %}

The MPNN function class is therefore a strict subset of all continuous invariant graph functions whenever its representation has non-isomorphic collisions.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-13.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="MPNN function class inside the space of invariant graph functions." caption="MPNNs approximate only invariant functions that are constant on their representation collisions. Cropped from the 2025 GDL GNN-expressivity lecture, slide 13." %}

Counting an induced subgraph is one excluded target. An induced subgraph on a vertex subset retains every edge of the original graph between those vertices, and ordinary MPNNs cannot in general count such patterns.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-14.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Induced substructure counting outside the MPNN function class." caption="Substructure counts provide invariant graph functions that ordinary message passing cannot always represent. Cropped from the 2025 GDL GNN-expressivity lecture, slide 14." %}

This leaves two linked questions: how should GNN expressivity be quantified, and how can architectures exceed the MPNN ceiling?

## The Weisfeiler--Lehman hierarchy

The graph-isomorphism problem is neither known to have a polynomial-time solution nor known to be NP-complete. The Weisfeiler--Lehman test is a combinatorial heuristic: if it distinguishes two graphs, they are non-isomorphic; failure to distinguish them is inconclusive. GNN expressivity is commonly placed relative to this hierarchy.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-16.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Definition and one-sided guarantee of the Weisfeiler--Lehman test." caption="WL supplies a computable graph-discrimination hierarchy with a one-sided isomorphism guarantee. Cropped from the 2025 GDL GNN-expressivity lecture, slide 16." %}

### Color refinement

One-dimensional WL initializes a color for every node, usually from its attributes or a common label.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-17.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Initial node colors for the WL test on two graphs." caption="WL begins with node labels before incorporating neighborhood structure. Cropped from the 2025 GDL GNN-expressivity lecture, slide 17." %}

At each round, it collects the multiset of neighboring colors.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-18.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Neighborhood color multisets in a WL refinement round." caption="Each WL update observes a node's current color together with the multiset of neighbor colors. Cropped from the 2025 GDL GNN-expressivity lecture, slide 18." %}

It hashes the current color and neighborhood multiset into a refined color, then repeats until the partition stabilizes.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-19.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Hashing neighborhood color multisets into refined WL colors." caption="Injective hashing refines node colors whenever their local colored neighborhoods differ. Cropped from the 2025 GDL GNN-expressivity lecture, slide 19." %}

If the two graphs have different color histograms at any iteration, WL distinguishes them. The update has the same structural form as an MPNN: aggregate a multiset and transform the result.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-20.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="WL color histograms used to distinguish two graphs." caption="Different stable color counts certify that the graphs are non-isomorphic. Cropped from the 2025 GDL GNN-expressivity lecture, slide 20." %}

Not every MPNN matches 1-WL. GIN was designed to do so: sum aggregation counts colors, while an MLP approximates the injective hash. Mean or max aggregation can collapse multisets that 1-WL keeps distinct.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-21.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GIN matching WL through sum aggregation and MLP hashing." caption="GIN reaches the 1-WL ceiling by making neighborhood aggregation and update sufficiently injective. Cropped from the 2025 GDL GNN-expressivity lecture, slide 21." %}

Higher-order GNNs seek stronger tests by representing tuples rather than single vertices.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-22.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="High-order graph neural network acting on tuples." caption="Higher-order models enlarge the represented object from nodes to tuples of nodes. Cropped from the 2025 GDL GNN-expressivity lecture, slide 22." %}

The common construction recipe is explicit: define a stronger WL variant, then design a neural architecture able to simulate that test.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-23.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Recipe from a stronger WL test to a more expressive GNN." caption="Provably stronger GNNs are often obtained by matching a stronger combinatorial refinement procedure. ### The k-WL test

The $$k$$-WL test colors ordered $$k$$-tuples $$\mathbf v=(v_1,\ldots,v_k)$$ rather than individual vertices. It considers tuples from $$V^k$$, including pairs that are not edges, so the computational state grows from $$|V|$$ nodes to $$|V|^k$$ tuples.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-24.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="k-WL coloring tuples of vertices including nonedges." caption="k-WL gains distinguishing power by refining colors on all ordered vertex tuples. Cropped from the 2025 GDL GNN-expressivity lecture, slide 24." %}

For each coordinate position, it replaces that coordinate by every possible vertex, collects the resulting tuple colors, and hashes the collection into a new color.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-25.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Neighborhood construction for a k-WL tuple." caption="A k-WL neighborhood varies one tuple coordinate at a time across the full vertex set. Cropped from the 2025 GDL GNN-expressivity lecture, slide 25." %}

Initialization must already encode graph structure. Two tuples receive the same initial color exactly when the coordinate mapping between them induces the same equality and adjacency pattern.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-26.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="k-WL tuple initialization by induced subgraph isomorphism." caption="Initial tuple colors record the isomorphism type induced by their selected vertices. Cropped from the 2025 GDL GNN-expressivity lecture, slide 26." %}

For $$k\ge2$$, increasing tuple order strictly strengthens the hierarchy, and sufficiently high order can separate all graphs of a fixed size. The corresponding $$k$$-GNNs mimic this tuple refinement.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-27.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Hierarchy of k-WL tests and k-GNN update." caption="Higher tuple order yields a hierarchy of stronger WL tests and aligned higher-order GNNs. Cropped from the 2025 GDL GNN-expressivity lecture, slide 27." %}

The guarantee is purchased with large neighborhoods and $$|V|^k$$ states. A provable expressivity hierarchy is therefore also a computational hierarchy.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-28.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Expressivity and computational cost tradeoff of k-GNNs." caption="k-GNNs have controlled expressive power but combinatorial tuple and neighborhood costs. Cropped from the 2025 GDL GNN-expressivity lecture, slide 28." %}

The lecture's main storyline follows successive sparsifications: the original $$k$$-GNN mimics $$k$$-WL, local variants reduce neighborhoods, and sparsity-aware variants reduce the tuple set itself. In each case, the neural design follows the new combinatorial test.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-29.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Timeline from k-GNN to local and sparsity-aware higher-order GNNs." caption="The higher-order storyline alternates between a more efficient WL variant and the architecture that realizes it. Cropped from the 2025 GDL GNN-expressivity lecture, slide 29." %}

## Structural encodings and cellular lifts

Substructure counts offer equivariant node identification without arbitrary random IDs. They can encode strong domain priors, capture information unavailable to MPNNs, and remain compatible with permutation.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-41.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Substructure-based equivariant node identification." caption="Matched substructures identify nodes through graph structure rather than external labels. Cropped from the 2025 GDL GNN-expressivity lecture, slide 41." %}

The recipe chooses a bank $$\mathcal H$$ of motifs, matches each motif throughout the input graph, and augments every node with the number of matches in which it participates.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-42.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Structural encoding recipe using a bank of matched subgraphs." caption="A structure encoding turns motif matches into additional node features. Cropped from the 2025 GDL GNN-expressivity lecture, slide 42." %}

A chemical example shows why the choice is meaningful: two molecules with similar local atom environments can contain different ring or functional motifs, and their node-wise motif counts expose that distinction to message passing.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-43.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Molecular example of motif-based structural encodings." caption="Molecular motifs provide domain-relevant structural evidence that atom-wise neighborhoods may miss. Cropped from the 2025 GDL GNN-expressivity lecture, slide 43." %}

Formally, matching maps a substructure into the graph while preserving the relevant adjacency pattern. Node-level encodings count embeddings or induced embeddings whose image contains that node.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-44.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Formal subgraph and induced-subgraph matching definitions." caption="Substructure matching defines the exact maps counted by structural encodings. ### Lifting graphs into cellular complexes

A cellular complex generalizes a graph with higher-dimensional cells while requiring intersections of cells to remain cells. It can encode vertices, edges, filled cycles, and larger regions as separate objects.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-48.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Graphs generalized into cellular complexes with higher-dimensional cells." caption="Cellular complexes make selected higher-order structures explicit elements of the domain. Cropped from the 2025 GDL GNN-expressivity lecture, slide 48." %}

Lifting maps a graph to a complex before message passing. A skeleton-preserving lift leaves the original vertices and edges intact, guaranteeing that the representation does not fall below the 1-WL baseline while adding cells for structures such as cycles.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-49.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Skeleton-preserving lifts from graphs to cellular complexes." caption="Graph lifting adds higher cells without deleting the original graph skeleton. Cropped from the 2025 GDL GNN-expressivity lecture, slide 49." %}

CW Networks pass messages among incident cells. With sufficiently large cycle or clique lifts, their distinguishing power exceeds MPNNs and can match or exceed specific higher-order WL baselines.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-50.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="CW Network message passing and expressivity statements." caption="CWNs perform message passing on lifted cells and gain power from which graph structures become cells. ## Subgraph GNNs and their symmetry limits

The motivating observation is that two whole graphs can be WL-equivalent even when their derived subgraphs are distinguishable by WL. A graph can therefore be represented as a bag of views, each exposing a different local or perturbed structure.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-55.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="WL-equivalent graphs with distinguishable subgraphs." caption="Subgraph GNNs exploit structural distinctions that appear only after decomposing the graph into views. Cropped from the 2025 GDL GNN-expressivity lecture, slide 55." %}

The aim is a model that remains tractable, equivariant, and domain-agnostic while becoming strictly more expressive than ordinary MPNNs.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-56.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Subgraph GNN goals and architecture overview." caption="Subgraph GNNs seek additional discrimination without committing to a domain-specific motif bank. Cropped from the 2025 GDL GNN-expressivity lecture, slide 56." %}

A subgraph GNN has three components: a policy that selects or constructs subgraphs, an encoder shared across the bag, and an invariant or equivariant aggregation that combines their representations.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-57.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Selection policy, encoder, and aggregation components of a subgraph GNN." caption="The subgraph policy, within-view model, and across-view aggregation are separate design choices. Cropped from the 2025 GDL GNN-expressivity lecture, slide 57." %}

Node-based policies create one view per original node. Common choices take an ego network, mark the selected node, or delete it. This one-to-one correspondence gives the bag an additional node-indexed structure.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-58.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Ego-network, node-marking, and node-deletion subgraph policies." caption="Node-based subgraph policies generate an ordered family of views indexed by original vertices. Cropped from the 2025 GDL GNN-expressivity lecture, slide 58." %}

DS-GNN, reconstruction-based GNNs, and nested GNNs differ in how these views are selected and how their node and subgraph features are aggregated.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-59.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Comparison of DS-GNN, reconstruction GNN, and nested GNN components." caption="Several subgraph architectures share the bag-of-views template but differ in policy and aggregation. Cropped from the 2025 GDL GNN-expressivity lecture, slide 59." %}

DS-GNN—also called Equivariant Subgraph Aggregation Networks—supports several selection policies and is provably more expressive than 1-WL.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-60.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="DS-GNN or ESAN subgraph aggregation architecture." caption="DS-GNN applies a shared equivariant model to systematically selected subgraphs and aggregates the results. Cropped from the 2025 GDL GNN-expressivity lecture, slide 60." %}

GNN-AK views an ordinary MPNN as a kernel operating on star neighborhoods and replaces the star with a richer induced subgraph around each node.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-61.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GNN-AK replacing star neighborhoods with induced subgraphs." caption="GNN-AK uplifts a base GNN by running it on structurally richer local subgraphs. Cropped from the 2025 GDL GNN-expressivity lecture, slide 61." %}

Its distinctive update lets node $$j$$ receive an embedding computed inside the subgraph centered at node $$i$$, creating interactions across the node and subgraph axes.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-62.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="GNN-AK cross-subgraph node update." caption="GNN-AK updates a node using its representations across subgraphs centered at other nodes. Cropped from the 2025 GDL GNN-expressivity lecture, slide 62." %}

### The symmetry of a bag of subgraphs

Because node-based subgraphs are indexed by original nodes, permuting the graph also permutes the view axis. The node and subgraph indices are coupled by one permutation rather than acted on by independent groups.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-63.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Coupled permutation symmetry of node-based bags of subgraphs." caption="A node-based bag is a tensor whose subgraph and node axes transform together under the original graph permutation. Cropped from the 2025 GDL GNN-expressivity lecture, slide 63." %}

This symmetry analysis places node-based subgraph GNNs below third-order Invariant Graph Networks and therefore below 3-WL. The extra views beat 1-WL, but they do not remove every higher-order ceiling.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-64.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Expressiveness landscape with subgraph GNNs below 3-IGN and 3-WL." caption="Node-based subgraph GNNs occupy a formal region between ordinary message passing and the 3-WL ceiling. Cropped from the 2025 GDL GNN-expressivity lecture, slide 64." %}

The natural next question is whether a modified bag construction can go beyond that upper bound.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-65.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Question of surpassing the 3-WL upper bound." caption="The fixed 3-WL ceiling motivates higher-order markings and ordered subgraph aggregation. Cropped from the 2025 GDL GNN-expressivity lecture, slide 65." %}

Ordered Subgraph Aggregation Networks mark ordered tuples of vertices rather than relying only on one-node subgraph operations. The order $$k$$ controls how much identifying structure is exposed.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-66.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="k-OSAN with ordered marked vertices and subgraph aggregation." caption="k-OSAN generalizes node marking to ordered k-tuples before shared graph processing. Cropped from the 2025 GDL GNN-expressivity lecture, slide 66." %}

The expressivity result is nuanced. One-OSAN captures DS-GNN and GNN-AK. In general, $$k$$-OSAN is strictly weaker than $$(k+2)$$-WL, while $$k$$-OSAN and $$(k+1)$$-WL are incomparable.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-67.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Expressive-power theorems for k-OSAN." caption="Ordered subgraph aggregation creates a distinct hierarchy rather than simply reproducing the next WL level. Cropped from the 2025 GDL GNN-expressivity lecture, slide 67." %}

Subgraph GNNs are attractive because they are equivariant, domain-agnostic, and tractable under restricted node-based policies. They are not an ultimate answer: large graphs make the bag expensive, and increasing $$k$$ raises the upper bound at exponential cost.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-68.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Benefits and limitations of subgraph GNNs." caption="Subgraph GNN expressivity remains coupled to the number and order of generated views. Cropped from the 2025 GDL GNN-expressivity lecture, slide 68." %}

The lecture ends by questioning a constraint shared by the entire storyline: exact permutation equivariance. Exact equivariance prevents false negatives in an isomorphism test, but one can instead present graph elements as tokens and learn the symmetry from data. TokenGT illustrates this route and is provably as expressive as a second-order invariant network.

{% include figure.liquid loading="eager" path="assets/img/blog/lectures/gdl-2025-05/slide-69.webp" class="img-fluid rounded z-depth-1" zoomable=true alt="Tokenized Graph Transformer learning permutation behavior from data." caption="TokenGT trades built-in permutation equivariance for a Transformer representation that can learn it from data. Cropped from the 2025 GDL GNN-expressivity lecture, slide 69." %}

The source's progression is therefore not a search for one universally expressive GNN. It is a sequence of choices about the represented object—nodes, tuples, motifs, cells, bags, or ordered markings—and the symmetry, preprocessing, memory, and runtime attached to that choice.
